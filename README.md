# Aftermath Stat Export

This export provides easier access to raw part stats for anyone who wants to build tools using them.

- **Aftermath parts:** [Aftermath Export](./Aftermath%20Export/) contains CSV and JSON exports.
- **Base game parts:** [Base Game Export](./Base%20Game%20Export/) contains CSV and JSON exports.

The root folder also includes [Aftermath_Parts_Stats.xlsx](./Aftermath_Parts_Stats.xlsx) for browsing the stats in a spreadsheet.
